Task 2: Finite Automata for Real-Time Validation

Project Description

This project uses Finite Automata to validate different types of user inputs. It checks whether the given input follows the specified rules.

Applications

1. Mobile Number Validation: Checks Indian mobile numbers with optional prefixes (+91, 91, or 0).
2. IPv4 Address Validation: Checks whether an IP address contains four valid octets ranging from 0 to 255.
3. Password Validation: Checks whether a password contains uppercase, lowercase, digit and special characters.

Technologies Used

- Programming Language: Python
- Concept: Finite Automata (DFA)
- Platform: VS Code / Python IDLE

Features

- Validates Indian mobile numbers.
- Validates IPv4 addresses.
- Validates password strength.
- Displays ACCEPTED or REJECTED results.

How to Run

1. Install Python.
2. Create a file named "task2.py".
3. Copy the Python code into the file.
4. Run the program using:

python task2.py

Expected Output

The program checks the given input and displays whether it is accepted or rejected by the validation rules.

Conclusion

This project demonstrates how Finite Automata can be used in real-time input validation. It helps identify valid and invalid inputs using simple state-based logic.
